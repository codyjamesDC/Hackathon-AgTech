⚙️ BUKID — Backend Flow

Supabase Edge Function · SMS Parser · PostgreSQL · Semaphore API

📥 Inbound — Semaphore SMS Gateway
📡

Semaphore Receives SMS

Farmer's text arrives at the Semaphore SMS gateway. Semaphore immediately forwards it as an HTTP POST to the Edge Function URL.

Content-Type: application/x-www-form-urlencoded or application/json
POST /functions/v1/sms-webhook
🦕 Supabase Edge Function — Deno Runtime
🔌

Step 1 — Payload Parsing

The handler reads the Content-Type header and decodes the body into a structured SemaphorePayload object with fields: from · to · message.

🧠

Step 2 — SMS Parser (parseSMS())

Text is uppercased and normalized. Must start with HIRAM. A regex anchor extracts:

Reply: Help Message

Sends Tagalog format hint back to farmer. Returns HTTP 200 so Semaphore doesn't retry.

🗄️ Supabase PostgreSQL — Database Lookups
👨‍🌾

Step 3 — Lookup Farmer

Queries farmers table with a case-insensitive ilike match on alias. Returns id, alias, full_name.

Table: farmers
if not found → reply "Farmer not found" SMS → return 200
🚜

Step 4 — Lookup Equipment

Queries equipment table with ilike on name. Returns id, name, status, daily_rate.

Table: equipment
if not found → reply "Equipment not found" SMS → return 200
🔍

Step 5 — Check Equipment Status

Evaluates equipment.status against allowed values.

✅ Available → proceed 🔧 Under Maintenance → reject 🚫 Retired → reject
if unavailable → reply in Tagalog → return 200
✍️ Database Write — Transaction Record
📋

Step 6 — Insert Transaction

Creates a new row in the transactions table:

Table: transactions
if insert fails → reply error SMS → return 200
📤 Outbound — Confirmation via Semaphore API
🌏

Step 7 — Format Tagalog Date (formatDateTagalog())

Converts ISO date (e.g. 2025-03-05) to a readable Tagalog string: Marso 5, 2025. Uses a static month-name map for all 12 months.

💬

Step 8 — Send Confirmation SMS (sendSMS())

Calls POST https://api.semaphore.co/api/v4/messages with the farmer's phone and a structured Tagalog message containing:

Salamat, Juan! ✅
Kumpirmado ang iyong booking:
• Kagamitan: Tractor
• Petsa: Marso 5, 2025
• Tagal: 1 araw
• Bayad: ₱1,500
Ref#: A1B2C3D4
✅

Step 9 — Return Success Response

Edge Function returns HTTP 200 with { success: true, transaction_id: "..." }. Supabase auto-syncs the new transaction row to the React dashboard in real time.

Dashboard polling every 10–15s via React Query
🛡️ Global Error Handling
⚠️

Unhandled Error Catch

A top-level try/catch wraps the entire handler. Any unexpected runtime error returns HTTP 500 and logs to the Supabase Edge Function console. Semaphore receives a non-200 only for true server errors — it will not retry on 200s, keeping the system idempotent.
