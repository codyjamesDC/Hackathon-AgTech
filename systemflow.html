🌾 BUKID — System Flow

SMS-based agricultural equipment management for Philippine cooperatives

📱 Farmer (Basic Phone)
👨‍🌾

Farmer Sends SMS

Farmer uses any basic keypad phone to text a booking request in Tagalog format:
HIRAM JUAN TRACTOR 03-05

via Semaphore SMS Gateway
⚙️ Backend — Node.js SMS Webhook
📨

SMS Webhook Receives Message

Semaphore forwards the inbound SMS as a POST request to the Supabase Edge Function (/sms-webhook).

🔍

SMS Parser

A forgiving Tagalog parser extracts:
alias · equipment name · start date · duration (days)

if format invalid → reply with help message
✅

Validate Farmer & Equipment

Looks up farmer alias and equipment name in Supabase (case-insensitive). Checks equipment status (Active / Under Maintenance / Retired).

🗄️ Supabase PostgreSQL
Availability check
✅ Available
📋

Create Transaction

Booking inserted into transactions table with status Confirmed. Operating hours logged for asset tracker.

🗄️ Supabase PostgreSQL
💬

Send Tagalog Confirmation

Farmer receives SMS reply with equipment name, date, duration, fee & reference number.
Ref#: A1B2C3D4

❌ Unavailable
🚫

Send Error Reply

Farmer gets an SMS explaining the equipment is under maintenance or retired, and is advised to contact the barangay technician.

synced to dashboard in real-time
🖥️ Admin Dashboard — React Web App
📅

Visual Master Schedule

Cooperative admin sees all SMS bookings auto-rendered as blocked calendar slots. Polls Supabase every 10s for live updates.

📡

Live SMS Feed

Dashboard shows a real-time feed of incoming farmer texts and system confirmation replies, auto-refreshing every 10 seconds.

🔧

Predictive Asset Tracker

Monitors cumulative operating hours per machine from transaction logs. Flags equipment approaching maintenance thresholds automatically.

📝

Manual Walk-In Entry (Override)

Admin can manually register offline walk-in farmer requests directly into the digital queue. All entries are logged in the audit trail.

📊

Digital Logbook & Compliance Export

Every transaction auto-populates the logbook. Admin can export accurate PhilMech / DA compliance reports with a single click.
